            This is Rak's own interpreter, compiled to WebAssembly and running in this
            page — the same lexer, parser and evaluator as rakc run.
            The module is fetched when the page opens, so the first run starts
            straight away. 
        

        

            A browser has no TLS stack, no event loop and no file system, so the
            browser build has no network, no async and no filesystem. Those
            builtins say so rather than pretending to work: fetch
            reports that the build has no HTTP client, and the async builtins
            are not registered at all.
        

        

            Randomness does work here: the module asks the page for it, and the
            page uses the browser’s own cryptographic generator.
