Rak Programming Language

Built for hackers and OSINT investigators by Ryuzaki

Rak simplifies security research by combining English-readable syntax with first-class hexadecimal support. Write network scanners, web scrapers, and forensic tools without wrestling with boilerplate.

Hello World

dump "Hello, World"

Quick Start

// Scan a target
scan "192.168.1.1" {
    range: [0x0016, 0x0050]
} {
    if open {
        dump fmt("Port 0x{:04X}", port)
    }
}

Syntax Overview

Rak uses English keywords and treats hexadecimal as a native type. No semicolons required in blocks, but statements outside blocks need them.

Variables

let x = 0xFF
let mut counter = 0
counter = counter + 1

Functions

fn add(a, b) {
    return a + b
}

let result = add(0x10, 0x20)

Control Flow

if x > 0x10 {
    dump "Greater"
} else {
    dump "Smaller"
}

loop {
    dump "Infinite"
    break
}

while counter < 0x0A {
    dump counter
    counter = counter + 1
}

Hexadecimal

Hexadecimal is a first-class citizen in Rak. All memory addresses, port numbers, and byte sequences work naturally in hex.

Literals

let port = 0x0050      // 80 in decimal
let signature = 0xDEADBEEF
let mask = 0xFF00FF00

Arithmetic

let a = 0x10
let b = 0x20
let c = a + b           // 0x30
let d = a & b           // 0x00
let e = a | b           // 0x30
let f = a ^ b           // 0x30

Formatting

dump fmt("0x{:04X}", port)    // 0x0050
dump fmt("0x{:08X}", sig)     // 0xDEADBEEF

HTML, CSS, JS Interop

Rak integrates with web technologies for scraping, DOM parsing, and JavaScript execution.

HTML Parsing

use web.html

fetch "https://example.com" {
    method: "GET"
} {
    let title = html.select("title").text()
    let links = html.select_all("a[href]")
    
    for link in links {
        dump link.attr("href")
    }
}

CSS Selectors

// Extract all images
let images = html.select_all("img")
for img in images {
    dump img.attr("src")
}

// Extract forms
let forms = html.select_all("form")
for form in forms {
    dump form.attr("action")
    let inputs = form.select_all("input")
    for input in inputs {
        dump fmt("{} = {}", input.attr("name"), input.attr("value"))
    }
}

JavaScript Execution

use web.js

let result = js.eval("JSON.stringify(document.cookie)")
dump result

let element = js.query("#username")
js.click(element)
js.type(element, "admin")

Example Scripts

Network Scanner

// Simple network reconnaissance
let target = "192.168.1.1"
let start = 0x0016   // 22 SSH
let end = 0x01F4     // 500

scan target {
    range: [start, end],
    threads: 0x64
} {
    if open {
        dump fmt("[OPEN] {}:{}", target, port)
        if port == 0x0050 {
            dump "[HTTP] Checking web server..."
            fetch fmt("http://{}/", target) {
                method: "GET",
                timeout: 0x1388
            } {
                trace headers
            }
        }
    }
}

Data Exfil Detection

// Monitor network for suspicious patterns
let subnet = "10.0.0.0/24"
let suspicious_ports = [0x1F90, 0x1388, 0x115C]  // 8080, 5000, 4444

scan subnet {
    ports: suspicious_ports
} {
    if open {
        dump fmt("[ALERT] Suspicious port open: 0x{:04X}", port)
        trace target
    }
}
