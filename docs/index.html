Project status

Built in the open. Docs lagging behind.

The interpreter, standard library, and IDE all run today. The spec, grammar, and guides aren't done yet, and this site will trail the code until they are.

Shipped

  • Rust interpreter
    Lexer, parser, tree-walking evaluator
  • First-class hexadecimal
    hex8 through hex64 with native arithmetic
  • OSINT statements
    scan and fetch with callback blocks
  • Standard library
    net, recon, crypto, encoding, web, file, json
  • Desktop IDE
    Tauri + Next.js editor with a dark hacker theme

In progress

  • *Formal spec & grammar
    The docs you're about to read
  • *Package manager
    Shareable Rak modules
  • *Compiler backend
    Bytecode and a faster runtime
  • *Type checker
    Static analysis on top of the AST
  • *JS execution
    web.js interop for browser automation
docs ~40% written

Documentation is still being written

Some sections of the current docs lag the implementation, and one describes a plan that doesn't exist yet. The core is real and runnable today. If you want to see what Rak actually looks like, the current docs are one page away.
