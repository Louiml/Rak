What's new in v0.3.1

Four new ways to write less code

All shipping in the compiler and the IDE today.

Pipeline |>

Chain calls left-to-right. data |> parse |> load reads top-to-bottom like a sentence.

Regex literals

Write /\d+/g inline. A / after a value is division; everywhere else it's a regex.

Binary patterns

Match byte slices by magic number: [0x89, 'P', 'N', 'G', ..]. Built for PCAP and file sniffing.

Traits

Implement Display, Iterable, Index on your types. They drive dump, for, and obj[key].

IDE with a tutorial

A first-run spotlight tour, settings, a file-tree sidebar with drag-and-drop, and SVG icons.

Bytecode VM

The VM runs the same code ~6x faster than the tree-walker. Compare with rakc bench.
