Rak language reference

Rak is for security research. Hex literals are a real type, syntax reads like English, and the standard library covers the network, HTML, and crypto work you'd otherwise hand-roll. Network scanners, web scrapers, and forensic tools end up shorter and easier to read.

This reference is a work in progress. Some sections lag the implementation, and a couple spell out plans before they exist. The examples are real and runnable.
