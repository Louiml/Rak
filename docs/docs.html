Rak language reference

Rak is a programming language for security research, OSINT, and systems work. Hex literals are a real type, syntax reads like English, and the standard library covers the network, HTML, and crypto work you'd otherwise hand-roll. Network scanners, web scrapers, and forensic tools end up shorter and easier to read.

Two backends, one language

Rak has a tree-walking interpreter (rakc run) and a stack-based bytecode VM (rakc vm). They share the same parser and AST, so a script that runs on one runs on the other. The VM is roughly 6× faster; use rakc bench to compare.

dump prints a value to the console. That's the whole program. No main, no imports, no boilerplate.

Syntax overview

Rak uses English keywords and newlines as separators. Hex is a real type, not a formatting trick. Statements inside blocks don't need semicolons; top-level statements do.

Variables

Bind with let. Add mut if you'll reassign later. Without mut, reassigning is an error.

Functions

Closures capture their definition environment (lexical scoping), so recursion and higher-order functions just work.

Control flow

Structs, enums, and match

match arms need a trailing comma. Patterns support literals, identifiers, tuples, arrays, struct fields, Some/Ok/Err, ranges, and | alternatives.

Hexadecimal

Hex is a real type in Rak. Memory addresses, port numbers, and byte sequences read like they look in a hex editor. Hex arithmetic stays hex.

Formatting

fmt("0x{:08X}", v) zero-pads to 8 hex digits. {:04X} pads to 4. The X upper-cases; x lower-cases.

Pipeline |> new

The pipeline operator threads a value into the next call, so data flows left-to-right instead of nesting inside-out.

The rule

x |> f becomes f(x), and x |> f(a, b) becomes f(x, a, b) — the left value is prepended as the first argument. Chaining is left-associative: data |> parse |> load is load(parse(data)).

The pipeline is a parse-time desugar, so it works identically on the interpreter and the VM — there's no new bytecode.

Regex literals new

Write a regex inline with /pattern/flags. A / after a value is division; a / anywhere else starts a regex, so let r = /\d+/g and a / b both parse correctly.

Flags

i case-insensitive, m multi-line, s dotall, x extended, g accepted (find is global anyway). Escape a literal / as \/.

Binary pattern matching new

Match a bytes value against a list of byte literals. A trailing .. matches the rest, so you can sniff magic numbers without knowing the full length.

Byte literals

Inside a bytes pattern, literals can be hex (0x89), decimal (216), or a char ('P'). Each is bounds-checked to 0–255. A pattern with .. matches the rest; without it, the lengths must be equal. Exact-length matching without .. also works against bytes.

Traits new

Traits are the language's protocols. Implement one on your type and the built-in syntax uses it automatically.

TraitMethodDrives
Displayfmt(self)dump, file output
Debugfmt(self)trace
Iterableiter(self)for x in target
Indexindex(self, key)obj[key] read
IndexMutset(self, key, value)obj[key] = v write
The receiver is the first argument

There's no self keyword. The receiver is passed as the first argument of the method — name it whatever you like. IndexMut::set must return the updated container (functional-update semantics, matching Rak's clone-on-read values).

Strings & arrays

Built-in helpers operate on strings, arrays, and maps. They're plain functions, not methods, so they work on both backends.

Interpolation

f"..." interpolates {expr} inline. fmt is the same idea with explicit format specifiers.

Error handling

Three pieces work together: Result/Option values, the ? operator, and try/catch/raise.

? unwraps an Ok/Some and short-circuits an Err/None out of the enclosing function (or into the nearest try). raise throws any value; catch e binds it.

Concurrency

spawn launches a thread, thread_join waits, and channel() gives a sender/receiver pair. TCP networking is built in.

JSON

json_parse returns native arrays, maps, ints, floats, bools, and nil. json_stringify serializes back. Real round-tripping, no hand-rolling.

Bytecode VM

Same language, two runtimes. The VM compiles the AST to a stack-based bytecode chunk and runs it — about 6× faster than the tree-walker on compute-heavy scripts.

Run it

rakc bench bench.rak prints both timings. The VM supports functions, recursion, arrays/tuples/maps, indexing, match, interpolation, regex literals, and the pipeline. Trait protocols and method dispatch are interpreter-only for now.
